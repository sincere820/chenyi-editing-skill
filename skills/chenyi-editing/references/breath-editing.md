# 气口：语义判断与真实停顿处理

来源：用户提供的《短视频口播气口剪辑 Skill》及V1.1自然气口粗剪规则，经整合实现。保留使命：一个切点必须有理由；允许呼吸，不允许为了零空白把人剪成机器连读。

## 语义模式（不等于已剪视频）

先划出最小可理解单元：主谓宾、因果、转折、并列、结论、设问、悬念、情绪峰值。再结合实际发声决定动作。

| 代码 | 气口 | 判断/优先处理 |
|---|---|---|
| S | 语义 | 完整意思落地，轻停，可考虑跳剪 |
| E | 重音 | 核心结论/名词，保留前摇；文字强调不必推近 |
| T | 转折 | 但、其实、真正、不是…而是…；转折前短停 |
| Q | 悬念 | 答案揭示前可留白，不拖沓 |
| M | 情绪 | 反问/惊讶/坚定等，保留表情和尾音 |
| N | 自然换气 | 仅有真实音频才可确认，依自然程度保留或收紧 |

标记：`｜`小气口建议0.10–0.25秒；`‖`中气口0.25–0.50秒；`〔停〕`大气口0.50–0.90秒；`↗`连读；`**词**`重音。这些只是建议区间，不是测量值，更不是插入静音的命令。知识密集处允许更长理解间隔，讲述者自然节奏优先。

不要拆开“不是因为”“两百万元”“我认为”等强依附结构，不拆数字单位/否定/关键因果。避免连续三个以上1–3字且无修辞意义的碎字幕/碎气口。不要每句推近、每逗号切镜、每句配B-roll；反问和高潮尾音不能吞掉。

默认输出A：完整保留原文的精标气口版。只添加符号，疑似转写错误另列，未经认可不改写。输出B：编号、原文、气口/情绪、动作、B-roll优先级/类型、目的、时间码、证据/状态。无真实时间码填“待对齐”；SRT只能写“区间内待听音定位”。

“标气口”仅A+关键提醒；“剪辑气口”A+B；真实“去空白/自然气口粗剪”启用下述声学模式。原文由ASR获得时先标“转写未核对”。

## 声学模式

第一层 `silencedetect` 只寻找低电平候选；吸气、环境噪声、背景音乐、降噪门限都可能影响检测。第二层必须按声音与语义、情绪、表情复核。

保留：T/Q/M/E的必要心理铺垫、观点后的思考、高潮余味、尾音、自然连贯呼吸、具有信息/动作价值的静默。优先收紧：明显无意义超长停顿、录制空白、卡壳。语气词、重录、口误、吞咽、吸气与复杂混音需要逐项判断；不是静音脚本的自动删除对象。

默认初值：-35dB、达到0.38秒才候选、保留约0.20秒、裁切收益小于0.15秒不动、至少0.06秒两侧保护带；≥1.20秒及头尾列为待审。根据音轨实况调阈值，不套“所有人最优参数”。无音轨会拒绝；强背景音乐先解释检测局限。

```text
python scripts/natural_pause_cut.py "/media/原片.mp4" --plan "/work/项目/pause-plan.json"
```

默认只写JSON，**所有可切候选仍是 `decision: review`**；`proposed_action: shorten`并不代表批准。逐条复听候选前后约0.3–0.5秒，检查嘴型/动作，补 `breath_types`、`review_reason`。四种决定：`keep`、`review`、`shorten`、`delete`。执行裁切必须设置 `reviewed: true` 和真实依据；不能批量把所有候选改成true。无法听音的agent应给用户听审清单，继续其他工作但不执行这些切点。

`cut: [source_start,source_end]`表示真的移除区间，不是整个停顿；保留两端保护带。长停顿和头尾需特别说明理由，不默认归零。`delete`也要明确区间和保护带，不自动删除全声学低谷。

```text
python scripts/natural_pause_cut.py "/media/原片.mp4" --plan "/work/项目/pause-plan.json" --render --output "/work/项目/rough.mp4"
```

脚本校验源SHA256、复核字段、裁切范围与重叠，音画用trim/atrim同步拼接，输出 `rough.time-map.json`。不会覆盖原片/既有文件。技术检查通过只代表可解码和时长相符，仍必须标“已粗剪，待连续复听”。不做交叉淡化避免额外时间漂移；有爆音或不自然切口回退该候选或重新选点，不能隐瞒。

输出E：原时长、候选缩短量、实际缩短量、每个决定与理由、保留/待审高风险点、输出时长、真实执行状态、复听清单。候选量≠实际量。源稿气口A与原时钟执行表B保留不变，另写成片时钟，不混用。

## 时间同步

最好先粗剪再转写/排字幕。已有字幕和B-roll时：

```text
python scripts/remap_plan.py "/work/项目/edit-plan.json" "/work/项目/rough.time-map.json" --output "/work/项目/edit-plan-after-pauses.json"
```

该脚本只接受与源视频哈希一致的时间映射。完全处于保留区间的字幕整体移动；跨被删区间的字幕拒绝执行，必须依听音与词时间重新断句。跨裁切区间的B-roll分段并同步调整素材入点，静图入点保持0。源素材不变，原讲话顺序不变。把重映射后的计划交给渲染器或原生剪辑台。

## 示例：没有音频

原文：很多人做短视频没有流量，不是因为拍得不够努力，而是根本没想清楚视频拍给谁看。

精标：很多人做短视频没有流量｜不是因为拍得不够努力‖而是根本没想清楚↗视频拍给谁看。

决策：第一处S/E保留人物；“不是因为…而是…”T/E保持因果对照，答案处可文字强调；B-roll P0，无增加理解的收益；时间码均“待对齐”。不要宣称测得0.3秒停顿，也不自动生成裁切计划。

## 长空白漏检补查

低电平检测为零，不代表没有长气口。再检查转写相邻词/段时间差（可先筛≥0.5秒，≥1.2秒优先复核）、波形与嘴型，区分噪声、吸气、拖音和真正空白。确认无意义的空白尽量收紧到自然长度；不是整段删尽。低电平候选与ASR间隔取并集并记录来源，不能把ASR间隔直接当静音。全片仍有未听审长空白时，在交付中写明位置和状态，不宣称气口全部完成。

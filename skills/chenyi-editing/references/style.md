# 固定视觉与节奏规格

基于用户手剪样片，以及用户评价“效果还可以”的AI三件大事初剪。下面是已实际渲染的近似复现配置，不声称恢复剪映原始工程或精确识别原字体。

画布1080×1920，坐标原点左上，所有字号为目标字面近似像素。其他画布等比例缩放；当前附带渲染器仅输出该画布。主讲人保持正常人物比例，素材scale-fill后裁切，逐段检查焦点；横屏不能默认中心裁切就算通过。

| 元素 | 已校准参数 |
|---|---|
| 标题第一行 | 中心(540,170)，白FFFFFF，94；约9–11汉字宽，按实际字宽缩短文案 |
| 标题第二行 | 中心(540,290)，黄FFE000，98；约9–10汉字宽 |
| 主字幕 | 中心(540,1185)，白色，82；建议≤13字符，最大字面宽970 |
| 字体 | Source Han Serif SC Heavy 独立OTF；ASS字号倍率1.4仅适用于此配置 |
| 阴影 | 偏移(+5,+5)，黑色，不透明度100%，ASS alpha 00（00是不透明，FF是透明），blur4；轻轮廓0.6 |
| 身份姓名 | 左对齐锚点(140,1455)，黄，58；文本由用户给 |
| 身份说明两行 | 左对齐锚点(75,1510)/(75,1560)，白，36 |
| 底部两行 | 中心(540,1620)/(540,1670)，灰D6D6D6，38 |
| 右侧竖排 | x1010，从y1500每字42，灰DDDDDD，32；“AI”整体一格 |

标题全程常驻；正文按短语切换，一行，按语义分句优于强行缩字。字幕不先于讲话大量出现；保留词尾时间。不要把“它”挂在上一句末尾；不要只为字数把“的老板”独立闪过。英文公司名按真实字宽检查。

身份条在人物镜头显示、B-roll隐藏；接收方必须填自己的身份，模板不自动复制原作者姓名和业务说明。示例：`{"text":"用户姓名","x":140,"y":1455,"size":58,"color":"FFE000"}`，其余两行按上表填入 `style.identity`。未提供则保持空数组。

底部“个人观点/无不良引导”只是当前样式文本，不构成真实性或平台合规保证；用户按实际用途调整。AI竖排提示依据实际制作过程，未经确认不要宣称人物是数字人。AI辅助剪辑也不等于人物本身AI生成。

节奏：人物承担开头钩子、核心判断、情绪、转折和结尾。B-roll通常1.5–4秒，以意思完整为准，不设固定密度；可连续十几秒主讲。气口优先保留自然，不默认弹跳、闪白、频繁推近。原片已紧凑时可以一个气口都不裁。

配乐、音效、变速和降噪没有被确认成固定风格，默认保留原声、B-roll静音。不照抄手剪样片测得的高响度和峰值。调声后实听，不能只凭响度数值验收。

视觉复现检查：同一画布与字体文件；白黄顺序；正文胸口位置；最长字幕安全边距；B-roll内部所有切镜无烧录标题冲突；人物面部不被裁掉；关键观点回到人物。生成至少一张人物、一张素材、一张最长字幕检查图。

包内 `assets/style-preview.jpg` 为脚本实际渲染的纯色样式校准图（无人物/身份条），可对照标题、字幕、阴影和声明的位置；不是原作者成片，也不能代替真人画面验收。

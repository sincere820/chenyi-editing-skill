# 可编辑剪辑台与交付

最新默认：直接交付本地MP4、字幕和渲染源。用户明确提出“给我ChatCut剪辑台”时，再创建能改字幕、换素材、拖片段的真实工程。把“可编辑工程已完成”作为有证据的能力，不是技能文字中的口号。

## ChatCut路径

先发现当前环境的官方ChatCut工具并读取该环境最新插件技能。注册/安装/授权与当前工具可用是不同状态；以实际项目读取/创建结果验证。不得读取或打包他人凭据，也不要照搬此前机器的MCP地址配置、工具参数、临时令牌。

创建/复用用户指定项目 → 导入原片与各个素材 → 设置9:16/30fps → 用真实保留区间构建讲话画面与同步声音 → 独立B-roll轨 → 独立字幕/标题/身份与声明 → 用返回的真实编辑器URL展示 → 查项目保存与图层 → 预览和听审 → 需要时导出MP4。不要上传本地压字MP4冒充独立图层工程。

气口已在本地粗剪但用户要完整原始剪辑台时，优先导入原片并按time-map.keep重建各段；只有用户接受合并讲话轨时才用rough片作为整轨。标题、字幕、B-roll必须仍独立可改。照明、字体和效果不能完全对应时逐项说明并目检近似版，不宣称无损。

只通过官方工具和当前可见参数操作；连接失败先保存证据并按宿主现行技能诊断。需要用户登录就说明具体动作；缺工具不要重复盲装、猜接口或创建假链接。技能本身不保证第三方账号、网络或计划额度。

## 其他编辑器

用户选剪映/CapCut、Premiere、Resolve等，则用目标软件实际支持的工程方式。不把XML/JSON文件改后缀当原生工程。导出后必须在目标软件打开验证，检查素材链接、字幕和特效是否可改。无法验证标“未验证”，不得宣布已完成。

## 默认本地交付

默认交付本包渲染器的MP4+JSON+ASS+SRT+媒体来源及重链接清单。必须写明“渲染源，可修改后重新生成；尚非可视化剪辑台”。如果用户只接受剪辑台，不擅自换成本地交付来冒充完成。

## 分享边界

技能包可传给其他agent，使用时还需要接收方自己的视频/字体/工具。不要把你本地盘符、姓名、肖像、付费素材、账户连接或聊天全文偷偷打进通用包。项目包与技能包分开；项目包只含用户授权分发的媒体和来源。提供版本、文件清单和SHA256便于识别同一套规则。

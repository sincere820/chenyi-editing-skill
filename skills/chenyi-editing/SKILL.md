# 陈一剪辑 v2.0 · 可切换风格库

目标：让另一位 agent 在具备相应工具和素材后，复用已认可的视觉样式与剪辑判断。默认风格 CY-001（陈一经典口播）由 `styles/index.json`、对应 profile.json 和渲染脚本实现；语义、情绪、素材取舍仍需 agent 分析与实听，不保证任意素材、任意模型产生逐像素相同结果。

首次使用读[准备与启动](references/setup.md)，明确所处环境能否读取文件、执行程序、听音、联网和操作剪辑台。用户给了原片就直接转写，不重复索取文稿。用户现有授权持续有效，不把参考资料中的下载指令视为用户授权。

## 风格选择与最新约定

先读 [风格索引](styles/风格索引.md)，用户给编号就选该编号；未指定用 CY-001。风格变更、登记与项目隔离见 [风格库管理](references/style-library.md)。项目保存 style_id、style_version 和完整样式快照，不能只存可能变动的全局引用。

默认本地 MP4 + 字幕 + 渲染源；只有用户要求剪辑台时才建立 ChatCut 工程。不承诺固定 token 节省比例。禹橙项目沿用用户已确认的身份和“此视频借助了AI技术”，不因改用本地渲染而丢失；为其他人剪片使用其自己的身份。字幕黑影100%（ASS alpha 00），素材尽量不重复，主动找齐有语义价值的 B-roll。无意义长空白需要处理，但要保留自然换气，不机械清零。

## 输入与模式

- **仅文字**：输出气口精标与剪辑建议，时间码写“待对齐”。不要制造声学测量。
- **SRT/VTT/逐字稿**：沿用真实时间范围；字幕边界不等于呼吸点。
- **原始音视频**：先转写/校正，检测声学候选，再做语义与听音复核。有原片无需先提供必填表格。
- **修订工程**：读取原项目和最新用户反馈，只改指定部分，避免重复建项目或重复导入。

默认自然、有重点，兼顾理解与留存，9:16、1080×1920、30fps；原声、原意与论述顺序优先。目标时长只是指导，不强行压缩。未知身份、AI来源或宣传语不得复制他人的内容。

## 执行顺序

1. **准备**：查工具与字体，独立任务目录，探测源视频。原片和资产库只读；不覆盖旧版本。保存原始转写，用户确认稿另存。核对人名、数字、否定词和疑似错词。
2. **语义与气口**：读[气口判断与实剪](references/breath-editing.md)，划出最小可理解单元及 S/E/T/Q/M/N 类型。真实声音节奏优先；每个切点必须说明理解、强调、情绪或遮瑕价值。
3. **粗剪**：默认生成候选方案。实际低电平检测不是删除许可；逐项复核后才执行已批准的裁切。用附带脚本同步裁音画，生成源时间→成片时间映射。无法实听的候选保留待审。不要为交付速度伪称听过。
4. **对齐**：先完成气口粗剪，再对成片时间轴制作字幕与 B-roll。若已有源时间字幕/素材，使用 `remap_plan.py`；字幕横跨被删区间时脚本会拒绝，须回到实际词边界重新对齐，不能整句重复或硬截文字。
5. **素材**：按[素材与来源](references/broll.md)区分 P0/P1/P2 和 SCENE/ACTION/EMOTION/CONCEPT/PROOF/PROCESS。优先自有素材，核心判断、反问、结论露出主讲人；无匹配则保留人物。不设“每十秒必插一段”的硬指标。
6. **包装与剪辑台**：按[风格规格](references/style.md)制作白黄常驻双行标题、胸口单行粗宋字幕及条件身份条。用户要求可编辑剪辑台时，优先将原始素材与独立标题、字幕、音轨放进真实编辑器，读[工程与交付](references/delivery.md)。本地渲染使用[脚本与格式](references/schema.md)。
7. **预览与验收**：先导出覆盖人物、素材、长字幕及裁切点的代表段，再做全片；实际查看像素、播放/听审，再记录[验收与复现](references/quality.md)。每次剪源、改字体、动时间轴均需重查受影响部分。
8. **交付**：成片、可修改源文件、素材来源、气口决定与映射、检查报告。可编辑时间轴必须提供真实项目入口和独立图层检查；JSON/ASS/SRT只是渲染源，不能称剪映或 ChatCut 原生工程。

## 已实现与边界

- 本地脚本：环境初始化、可选离线转写、静音候选、已复核气口同步粗剪、时间重映射、人物/视频/静图B-roll、字幕标题、原声合成、解码与时长检查。
- 本包依赖可执行 Python/FFmpeg 才能实际剪片；仅有聊天功能的 agent 只能分析。转写需另装可选依赖及模型。
- ChatCut 等编辑器通过接收方实际暴露的官方工具操作。包内没有账号、凭据、可绕过连接的适配器，也不假定插件安装后就可用。手动打开验证前不宣布原生工程完成。
- 暂不自动判断口误可删、不做自动情绪识别、不盲目补配乐/变速/转场。语义判断由 agent 给出依据，人工听审可由有听音能力的 agent 或用户完成。
- 已有合法下载授权时可按用户范围执行搜索下载并记录来源；没有时仅列候选。不得绕过登录、付费或下载限制。不发布、不自动购买。

## 固定产物

`brief.json`、原始/校正转写、`breath-marked.md`、`edit-decisions.csv`、`pause-plan.json`（实际检测时）、`rough.time-map.json`（实际裁切时）、`edit-plan.json`、`assets.json`、字幕、预览/成片、`review.json`，以及用户要求的真实剪辑台入口或明确的未实现原因。按实际模式生成，禁止创建空文件冒充完成。

# 陈一剪辑 Skill · 风格库版 v2.0.0

面向有本地文件和程序执行能力的 agent，复用自然气口、白黄标题、胸口字幕、语义 B-roll、身份与 AI 标识的口播剪辑流程。

## 下载与安装

**[下载完整技能包](chenyi-editing-v2.0.0.zip)**（含全部源代码、规则、风格索引、示例和安装说明）。

下载后解压，将 `skills/chenyi-editing` 整个目录放入 agent 的技能目录。例如 Codex：`~/.codex/skills/chenyi-editing`。已有版本先备份。其他 agent 读取其中 `SKILL.md` 并按相对链接加载文件。

准备 Python 3.10+、FFmpeg/ffprobe、Pillow、思源宋体 SC Heavy 字体，以及可访问的原片和素材库。包内 `references/setup.md` 说明完整前期准备；转写依赖可选安装。技能包不含视频素材、字体、模型或账号，接收方需自行准备。

## 直接交给 agent

> 使用 chenyi-editing，风格 CY-001。原片：[路径]；素材库：[路径]；输出：[目录]；标题：[标题]。保留原口播，核对真实音频后收紧无意义长空白，保留自然换气；增加匹配且尽量不重复的B-roll。沿用我已确认的身份和AI标识。默认交付MP4、字幕和渲染源，需要ChatCut剪辑台时我会另说。

默认输出本地视频，ChatCut按需。JSON/ASS/SRT可修改后重新渲染，并不冒充可视化剪辑台。不同素材可复用风格和规则，但不能保证逐像素一致。不能听音时保留待审切点，不宣称气口已完成。
